A FEW LITTLE DETAILS

Good to know.

Does my code leave my machine?+

Lilt reads and serves your workspace locally. GitHub operations connect to GitHub, and a coding agent you explicitly run follows that provider's data settings. Lilt doesn't upload your repository to a hosted workspace.

Can I use my existing coding agents?+

Yes. Lilt connects to supported local harnesses, including Claude Code, Codex, Gemini CLI, Cursor Agent, OpenCode, Aider, and Goose. Install and authenticate the tools you want to use separately.

Is Lilt a full code editor?+

Lilt centers on reading, navigation, and code review, with quick file editing when you need it. It includes Git and pull request workflows, rich file views, and optional language-server navigation.

Can I run it on a remote machine?+

Yes, on a persistent server or container. Keep access private using a VPN, an authenticated proxy, or an authenticated tunnel. Anyone who can reach an unprotected Lilt server can access and edit the workspace.

What's the story behind Lilt?+

Lilt is an independent project by Aryan Rathore, built on the MIT-licensed px0 by Arpit Bhayani. It keeps that lightweight core and adds a fresh identity and a calmer interface. The original license is preserved in the repository.
